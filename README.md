# Spotify Music Converter

โปรแกรมแปลงและดาวน์โหลดเพลงจาก Spotify คุณภาพสูง (MP3 320kbps, FLAC, M4A, WAV) พร้อมฝังภาพปกความละเอียดสูงและ ID3 Tags ครบถ้วน

## ฟีเจอร์หลัก (Features)
- รองรับทุกลิงก์ Spotify: เพลงเดี่ยว, อัลบั้ม, เพลย์ลิสต์ หรือค้นหาด้วยชื่อเพลง
- คุณภาพเสียงสูงสุด: MP3 320kbps, FLAC, M4A, WAV
- ฝัง ID3 Tags และรูปปกอัตโนมัติ
- แปลงเป็นคิวแบบ Batch Download
- Modern Spotify Dark Theme UI

## การใช้งาน
1. ติดตั้งไลบรารี: pip install -r requirements.txt
2. เริ่มโปรแกรม: py main.py
