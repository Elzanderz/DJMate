# DJmate - Pro DJ Harmonic Suite

ชุดเครื่องมือและแอปพลิเคชันสำหรับ DJ: วิเคราะห์คีย์เพลง (Camelot Wheel), BPM, Cue Points, สตรีมและจัดเตรียมคลังเพลง รองรับการส่งออก Rekordbox XML, M3U8 และจัดระเบียบโฟลเดอร์สำหรับงานดีเจ

## ฟีเจอร์หลัก (Features)
- 🎧 **Harmonic Key & BPM Analysis**: ตรวจจับคีย์เพลงและจัดเรียงเพลงตามวงล้อ Camelot Harmonic Wheel สำหรับการมิกซ์เพลงที่กลมกลืน
- 📁 **Smart Folder & Queue Management**: กำหนดโฟลเดอร์ปลายทาง จัดแยกตามเพลย์ลิสต์ หรือรวมโฟลเดอร์เดียวได้อย่างอิสระ พร้อมระบบจดจำโฟลเดอร์
- 🔍 **Unified Music Search**: ค้นหาเพลงจากคลังเพลงในเครื่องและช่องทางออนไลน์ (SoundCloud, Spotify, Beatport, Bandcamp)
- 📦 **Rekordbox & DJ Drive Export**: ส่งออกไฟล์คลังเพลง, Cue Points และ Rekordbox XML สำหรับใช้งานกับ Pioneer CDJ / Standalone Controller ได้ทันที
- ⚖️ **EBU R128 Audio Normalization**: ปรับระดับความดังของเพลงให้อยู่ในมาตรฐานเดียวกัน (-14 LUFS / -12 LUFS)
